# Khairul Afiq portfolio

This portfolio is set up for GitHub Pages. Before the first deployment, place the six original images listed in [`client/public/images/README.md`](client/public/images/README.md) in that folder.

## Publish it

1. Create a public GitHub repository named `portfolio` (or choose another name).
2. In the repository **Settings → Pages**, set **Source** to **GitHub Actions**.
3. Upload this project to the repository's `main` branch. The included workflow builds and deploys it automatically.
4. Your site will be available at `https://<your-github-username>.github.io/<repository-name>/`.

For the cleanest address, name the repository `<your-github-username>.github.io`. The workflow automatically supports both repository names and this root-domain format.
